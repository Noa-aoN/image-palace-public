# 構成と、1枚の絵ができるまで

本体の `docs/architecture.md` から、**公開して差し支えない範囲**を書き起こしたものです。
運用事情（本番の台数・鍵の状態・障害の記録）は含めません。

---

## 全体

```
ブラウザ / PWA
   |                        画像の実体は CDN から直接
   |-------------------------------------------> Cloudflare CDN --> R2
   |
   v
Cloudflare Workers (Next.js 16 / OpenNext)
   |  REST（devise-token-auth のトークン）
   v
Fly.io sin
   app    : Rails 8.1 API (Puma)  ---> Neon PostgreSQL
   worker : Solid Queue           ---> Neon PostgreSQL / OpenAI / fal.ai / R2
```

- **app と worker は別プロセス。** 同居させていた時期は、ジョブが詰まると API ごと
  無応答になった。生成は worker が持ち、Web を止めない
- **キューは PostgreSQL**（Solid Queue）。Redis を運用対象から外せた
- **アプリは DB の隣に置く。** Neon に東京リージョンが無く DB が ap-southeast-1 にあるので、
  アプリを `sin` へ寄せた。DB 往復は 70.2ms から 2.4ms になった。
  このアプリの待ち時間は**往復の本数**で決まるので、ここが一番効いた
- **画像は CDN から直接配す。** R2 の直配信はしない（`CDN_BASE_URL` で切り替える）

## 1枚の絵ができるまで

```
POST /api/v1/items         （カードを作る。ここでクレジットを引く）
   |
   |-- GenerateBriefJob     単語 --> 説明文 --> 情景の指示（shared_briefs に語ごとに貯める）
   |
   v
GenerateImageJob
   |
   |-- 1. カードの行を押さえる（with_lock）
   |-- 2. 注文の指紋を作る（PromptFingerprint）
   |-- 3. 同じ注文の絵が既にあるか（shared_medias / アドバイザリロックで1本に絞る）
   |      あれば添付して終わり（キャッシュ分も使用量に記録する）
   |-- 4. 無ければ供給側へ（OpenAI / fal.ai）
   |-- 5. 収める（切り出し --> WebP --> サムネ 480px --> ぼかしの下絵）
   |-- 6. R2 へ保存し、カードへ添付
   |-- 7. completed にして、お知らせを積む
   |
   失敗したら: 指数バックオフで3回まで再送 --> それでも駄目なら failed にして、
               返金の条件を満たせば1クレジット返し、お知らせを積む
```

画面はポーリングで状態を見ます（数十秒で届く）。

### 「単語 → 説明文 → 情景」の2段階にした理由

単語をそのまま画像生成へ渡すと、多義語・専門用語・固有名詞で**別のものの絵**になります
（「アポロ」が神か宇宙計画か）。先に意味・説明を作り、それをもとに情景の指示を書けば、
その語の絵になります。

説明文は**語ごとに共有**します（`shared_briefs`）。同じ語の2人目以降は、文章生成の
呼び出しが要りません。

### 絵の共有（このアプリの原価設計）

`shared_medias.normalized_prompt` が UNIQUE です。鍵は「正規化した指示」だけでなく、
**比・モデル・品質・保存する長辺**まで含みます。品質を上げたのに前の絵が返る、という
取り違えを防ぐためです。

- 「ほかの人に使わせない」と決めている人の絵は、その人だけの鍵で置く
- **取る側は変えない。** ほかの人が作った絵は今までどおり使う
- 出来上がったものの作り直しだけは、キャッシュを迂回する（同じ絵を返しても意味が無い）

実測した共有率は **0.9%**（344回中3回）。利用者が少ないうちは重なりません。

## クレジット（お金の流れ）

| 種別 | 入れ物 | 期限 |
|---|---|---|
| お試し・毎月の無料枠・買い切り・キャンペーン | `credit_grants` | 受け取りから3ヶ月 |
| サブスクの月間枠 | `subscription_credits` | 次回リセットまで |

- 消費順は **期限の近いグラント → サブスク枠 → 買い切り**（失効ロスが小さい順）
- 期限切れは遅延評価（読むとき・引くときに除外）
- 期限を1か所（`Billing::CreditExpiryPolicy`）に寄せている。以前は定数と規約と画面に
  別々に書いてあり、長さを変えるとずれた

生成を積む**前に**引きます。積んでから足りないと分かると、絵だけ作られて課金できません。

## 安全の線

- 画像は libvips へ渡す前に**マジックバイトで allowlist**（PNG / JPEG / WebP）。
  SVG は許可しない（外部ライブラリ委譲が任意コード実行の経路になる）
- 使わないローダモジュールは**イメージから削除**し、残りも allowlist で塞ぐ。
  防御が外れたら気づけるように、spec で固定している
- 利用者の文字列が OpenAI へ渡る経路には、必ず検査（Moderation）を通す。
  外部 API の障害では**通す**（検査できないことを理由にサービスを止めない）
- 乱用対策は2層。口ごとの速度制限（IP）と、1人あたりの総量（1時間・1日）
- CSP は組み立てを1か所に集め、テストで回帰を止める

## デプロイ

- バックエンド: Fly.io（手動デプロイ）。マイグレーションは `release_command` で実行
- フロントエンド: Cloudflare Workers（`npm run deploy`）
- **staging は無い。** main へのマージは本番反映ではない
- 戻せない変更（列の削除・型変更）は段を分ける（追加 → 移行 → 削除を別のデプロイに）
